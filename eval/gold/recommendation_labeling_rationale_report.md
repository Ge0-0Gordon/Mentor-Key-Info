# Recommendation Gold Labeling Rationale Report

## Scope

- Input review CSV: `recommendation_quality_review.csv`
- Mentor extraction source: `mentor_results.jsonl`
- Source mentor fields used through `mentor_results 中的原始导师字段`: 导师姓名、性别、城市、职业年限、可辅导学员职级、行业标签、从业经历、背景经验。
- Output labels: `good`, `acceptable`, `bad`.

> Note: This is a first-pass expert-style labeling set generated from the available mentor profile fields. It is suitable for running initial Hit@K / MRR / NDCG evaluation, but a business owner should still spot-check cases where the business preference is subjective.

## Labeling Rubric

| label | meaning |
|---|---|
| good | Strong fit for the case; should reasonably appear in Top 5. Usually matches the core role/industry/help need, or satisfies an important hard constraint. |
| acceptable | Partial but usable fit; can appear in Top 10, but lacks one important signal such as exact role, target company/institution, or case-specific industry. |
| bad | Weak or misleading fit for this case; mainly generic career coaching or unrelated signal, or violates a key constraint. |
